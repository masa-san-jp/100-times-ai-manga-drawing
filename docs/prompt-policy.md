# 共通の作画条件

漫画ページの共通条件は [prompts.py](../src/manga_drawing/prompts.py) の `RULES` で定義します。`mono-v3-strict` から、Geminiの `systemInstruction` としてページ指示・添付画像とは別に送信します。ページ指示の直接編集でも、この共通条件は保持します。

| 対象 | 条件 |
| --- | --- |
| 構成 | コマ数・順序・枠・吹き出し・セリフ・人物配置を保持。明示された変更だけを適用 |
| 描き直し | 全コマを同じ精度の明瞭な線画へ描き直す。ラフや棒人間をコピーして残さない |
| 人物 | 採用したリファレンスの造形・衣装へ統一。リファレンスのポーズは強制しない |
| 演出 | 指示にもネームにもない集中線・効果線・漫符・擬音などを追加しない |
| 背景 | 資料で指定されたものだけを描く。空白を勝手に埋めない |
| 注釈 | 作画用の番号・矢印・説明ラベル等を描画しない |

同一対象への指示が競合した場合は「今回の修正 → ページの文章指示 → 演出指定 → 指示書画像 → ネーム画像」の順です。変更対象以外はネームの構成を保持します。

システム指示・ページ指示・参照画像・テンプレート版は生成依頼時のsnapshotとハッシュへ含めます。待機中・過去の依頼へ新ルールを差し込まず、送信時もそのsnapshotを使います。ページ詳細の指示確認と過去候補の履歴で、適用された共通条件を確認できます。

システム指示は画像生成モデルの完全遵守を保証する機能ではありません。演出の無断追加、コマ構成の変更、ラフの残存、人物の不一致をページごとに確認し、要修正判定と具体的な修正指示へつなげます。自動の品質合格判定・追加課金を伴う自動再生成は行いません。

作例001の現在のテイク1は `mono-v2` で生成したものです。この変更で再生成・採否変更は行っていません。新しい共通条件の画像品質上の効果は、実生成で未検証です。

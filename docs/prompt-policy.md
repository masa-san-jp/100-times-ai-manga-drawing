# プロンプトの原文保持

正本は[作者のプロンプト原文](source-prompts/README.md)です。独自に追加していた `mono-v3-strict` の作画ルール・優先順位は、新しい生成依頼から撤去しました。

現在の `author-original-v1` は記事の原文を使用します。通常モードは原文へユーザーが入力したページ指示・演出・修正だけを追記します。全文指定モードでは指定本文をそのままuser本文へ送り、独自のsystemInstructionを付加しません。画面でも送信されない通常欄は無効にし、実際の全文編集欄を表示します。

manifest.jsonの各ページにprompt_overrideを指定すると、登録から送信までその本文を維持します。再登録時に省略した場合は既存の全文を保持し、明示nullで解除します。

本文・参照画像・版は依頼時のsnapshotとハッシュへ固定します。過去のsnapshotにsystem_promptがある場合だけ、その保存値を使って互換性を維持します。旧テイクの履歴を新しい原文で置換しません。

本文一致のテストは、画像での指示遵守を証明するものではありません。公開作例のテイク2は撤去前の独自指示で生成した画像です。

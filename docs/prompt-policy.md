# 原文とページ指示の分離

正本は[作者のプロンプト原文](source-prompts/README.md)です。原文を通常画面で全文編集する機能は撤去しました。ページ詳細では「登録済みの原文」を参照専用で表示し、利用者は「作画指示」「修正内容」を編集します。送信内容の確認も参照専用で、保存データを変更しません。

`author-original-v2-page-notes` は、登録したbase_prompt（未指定なら作者の共通原文）へ、ユーザーが入力したページ指示・演出・修正だけを追記します。独自の共通ルールやsystemInstructionを追加しません。追記が空なら原文のままです。

manifest.jsonの各ページにbase_promptを指定すると、原文として登録します。再登録時の省略は既存値を維持し、明示nullで解除します。旧prompt_overrideを持つページにbase_promptを明示登録した場合は、旧overrideを解除し、新しい原文を使用します。両本文の同時指定は拒否します。

旧データ/APIのprompt_overrideによる完全置換は互換性のため読み込めます。通常画面から編集保存した際は原文をbase_promptへそのまま移し、通常欄の指示を追記できる形式へ変換します。

本文・参照画像・版は依頼時のsnapshotとハッシュへ固定します。過去の指示や作例画像を現在の本文で置換しません。公開作例は原文復元後のテイク3です。今回のUI変更で再生成・採否変更は行っていません。

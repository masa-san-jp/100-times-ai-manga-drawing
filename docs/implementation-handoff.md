# 実装担当者への引き継ぎ

## 今回の完成範囲

v1モック版を実装する。APIキーと外部通信を使わず、資料登録、大量ページのバッチ処理、ページごとの採否、プロンプト修正、却下ページだけの再生成、書き出し、バックアップまで動作させる。

模擬APIは画像を返す実動作の代替実装とし、遅延と障害を再現できるようにする。Gemini接続だけを無効なプレースホルダーとする。UIやキュー、審査、画像保存を仮の画面や空の関数で済ませない。

> 各Issueの実行証拠と未解決事項を記録し、最後に独立した2名の実装レビューを通してください。設計レビューのPASSを実装レビューの代わりに使わないでください。完了時は「モック版完成・実API未接続」と報告し、T01〜T13の結果、起動手順、既知の制限、I15の残作業を引き継いでください。

## 着手条件と完了報告

この引き継ぎ時点でアプリは未実装である。現行の設計文書を含む作業フォルダーまたはファイル一式を実装担当者に渡す。Gitリモートだけを渡す場合は、設計文書がリモートへ反映されていることを先に確認する。

I01〜I14はローカルのIssue識別子であり、GitHubへ起票済みではない。外部Issueの作成は別途権限と運用に従う。実装者はローカル計画だけでも着手できる。

完了報告には、変更内容、Issue別の結果、実行コマンドとテスト結果、両テーマの画面確認、2名の実装レビュー、運用手順、未対応の実API機能を記載する。T14未実行でもモック版完成は可能だが、実API対応済みとは報告しない。

# 現在の対応範囲

ローカルの Web 画面で作品と話を管理し、キャラクター設定画の生成・採用、漫画の一括生成、ページごとの採否と再生成、PNG 書き出しを行えます。入力画像と生成履歴はアプリの保存先に記録します。

漫画の出力はモノクロです。Gemini Batch API の結果はワーカーが非同期で取得します。入力項目と上限は[マニフェスト仕様](manifest.md)、操作は[利用手順](operations.md)を参照してください。

キャラクターリファレンスの必須記載と公開作例の検証状況は [#2](https://github.com/masa-san-jp/100-times-ai-manga-drawing/issues/2)、利用条件の決定は [#9](https://github.com/masa-san-jp/100-times-ai-manga-drawing/issues/9) で追跡しています。

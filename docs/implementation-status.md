## キャラクターリファレンス工程の追加

キャラクタースケッチから設定画を生成して採用する工程が欠落していたため追加しました。人物ごとの生成指示、バッチ生成、採否、指示修正と対象人物だけの再生成、テイク別ファイル保存を実装しています。ページ生成は原案スケッチの直接添付から、採用済み設定画の添付へ変更しました。既存のページ画像・履歴は保持します。

`character_references.py` とDBスキーマ3で、原案の資料版・生成タスク・採用ポインターを分離します。永続キュー、ジョブ、チャンク、再試行、復旧、料金枠は既存エンジンを共用します。内部の生成用プロジェクトは `purpose=character_references` と親作品IDで明示し、作品・話一覧、漫画ページ数、漫画の出力先計算には含めません。これによりリファレンスの失敗や修正が漫画ページの採用状態を変更しません。

生成入力には原案の版を、ページ生成入力には採用したリファレンスの候補IDと画像ハッシュを固定します。原案更新後の古い候補採用を拒否し、採用変更前に作ったページ生成計画は作品の版検査で失効させます。

[キャラクターリファレンス工程の実行・検証とAI内部レビュー記録](character-reference-acceptance.md)。実資料4人分のテイク1を生成し、エージェントが作画基準として暫定選択しました。4ページのテイク5に適用して実生成を実行しています。作者の品質採否は未実施です。

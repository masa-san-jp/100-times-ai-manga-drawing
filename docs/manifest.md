# マニフェスト仕様

`manifest.json` は、作品のフォルダーにある資料を人物・シーン・ページに対応付けます。画像パスはそのフォルダーからの相対パスです。

```sh
uv run manga manifest --input ./my-comic --title "漫画の題名"
```

`キャラクタースケッチ/`、`ネーム/`、`作画指示書/` の直下を調べます。各フォルダーがない場合は順に `characters/`、`name/`、`instructions/` を使います。ネームと指示書はファイル名先頭の数字で対応付けます。既存ファイルの上書きには `--force` が必要です。登録後はページ詳細の「登場人物」で人物を指定できます。

| 項目 | 必須・型・上限 | 用途と再登録時の挙動 |
| --- | --- | --- |
| `schema_version` | 必須・整数・1 | 形式の版 |
| `title` | 必須・文字列・1〜200文字 | 作品名 |
| `base_prompt` | 任意・文字列・1〜20000文字、または `null` | ページ側の本文指定がないときの既定値。省略時は既存本文を保持し、`null` は既定値を解除 |
| `characters` | 任意・配列 | 人物資料。省略時は追加・更新なし |
| `characters[].key` | 必須・文字列・1〜100文字 | 人物を識別する一意のキー |
| `characters[].name` | 必須・文字列・1〜200文字 | 表示名 |
| `characters[].height_cm` | 任意・数値・0より大きく500以下、または `null` | 身長。省略または `null` は未設定 |
| `characters[].images` | 必須・文字列の配列・1枚 | スケッチへのパス |
| `scenes` | 任意・配列 | シーン資料。省略時は追加・更新なし |
| `scenes[].key` | 必須・文字列・1〜100文字 | シーンを識別する一意のキー |
| `scenes[].description` | 任意・文字列・20000文字まで | 説明。省略または空文字で説明なし |
| `scenes[].images` | 任意・文字列の配列・7枚まで | 資料画像。省略時は空配列 |
| `pages` | 必須・配列・1〜500件 | 話のページ。掲載したページを更新 |
| `pages[].number` | 必須・正の整数 | ページ番号。話内で重複不可 |
| `pages[].name` | 必須・文字列 | ネーム画像へのパス |
| `pages[].instructions` | 必須・文字列 | 作画指示書画像へのパス |
| `pages[].characters` | 任意・文字列の配列・5人まで | 登場人物のキー。省略または空配列で人物指定を解除 |
| `pages[].scene` | 任意・文字列または `null` | シーンのキー。省略または `null` で指定を解除 |
| `pages[].page_prompt` | 任意・文字列・20000文字まで、または `null` | 追記する作画指示。省略または `null` は指示を保持し、空文字で解除 |
| `pages[].base_prompt` | 任意・文字列・1〜20000文字、または `null` | 作画本文。ページの明示値が全体既定値に優先し、`null` でページ本文を解除 |
| `pages[].prompt_override` | 任意・文字列・1〜20000文字、または `null` | 旧形式の送信本文。省略時は既存値を保持し、`null` で解除。ページの `base_prompt` と両方に本文を指定するとエラー |
| `pages[].directions` | 任意・配列 | 番号付きの演出指示。省略または空配列で解除 |
| `pages[].directions[].marker` | 必須・文字列・1〜100文字 | ページ内で一意の演出番号 |
| `pages[].directions[].text` | 必須・文字列・20000文字まで | 演出本文 |

`null` を受け付ける項目は表に記載しています。資料画像は PNG または JPEG、1ファイル20MiB・40MPまでです。登録1回につき1GiB、1話500ページ、1ページ5人、人物の画像1枚、シーンの画像7枚までです。生成依頼の上限は添付14枚、本文と画像を含む送信データ20MiBです。

```json
{
  "schema_version": 1,
  "title": "短編",
  "pages": [
    {"number": 1, "name": "ネーム/01.png", "instructions": "作画指示書/01.png"}
  ]
}
```

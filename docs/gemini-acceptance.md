# I15 Gemini接続の実装と検証

2026年10月18日。接続コードとオフライン検証を完了。実APIへの送信、実作画の品質評価、実利用明細の照合、T14は未実施であり、I15全体の完了とはしない。

## 実装

- google-genai 2.31.0を任意依存として固定した。既定mockはキーなしで起動する。
- 画像入りJSONL、native Batch API、非同期回収、候補登録、ページ単位の修正再生成を接続した。
- SDK自動再試行を無効化し、成否不明は照合に回す。累積要求上限とバッチ予算予約を送信前に検査する。
- Webとworkerがネットワーク待機中も書込・heartbeat・バックアップを継続できる。
- UIに稼働provider、送信予約残数、上限待ち、候補ごとの生成元を表示する。APIキーは環境変数またはGit対象外のローカル`.env`で扱う。

## 検証結果

`uv run --extra gemini pytest -q`（Chromium有効）で65件成功。内訳は既存40件とGemini接続25件。ruff check/formatも成功。

Gemini試験はインメモリーの偽APIとSDKのHTTP MockTransportを使い、Googleへの通信は行わない。SDKが429で隠れた再送をしないこと、通常UI相当の予算単位省略、画像入力・出力、修正再生成、累積上限、上限縮小、事前障害の有限回復、壊れた応答を検証した。実サービスの提供モデル・schema・利用枠を保証する試験ではない。

Starlette TestClientのhttpx非推奨警告が1件ある。試験失敗はない。

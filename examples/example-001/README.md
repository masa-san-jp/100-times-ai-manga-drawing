# 作例001の制作資料

この作品で使った資料を、次のフォルダーに入れてください。

| フォルダー | 入れるもの |
| --- | --- |
| `キャラクタースケッチ/` | 登場人物の顔・全身・服装など、見た目が分かる設定画 |
| `ネーム/` | ページごとのコマ割り・セリフ・人物配置が分かる下描き |
| `作画指示書/` | ページごとの描き方や、ネームを補足する指示 |

ネームと作画指示書は、対応するページが分かる名前にしてください。たとえば、1ページ目なら両方のフォルダーで `001.png` にします。既存の名前で対応が分かる場合は、そのままで構いません。

資料を入れた後、アプリへの登録に必要な設定ファイルは実装担当が整えます。

このフォルダーの資料は、事例としてリモートリポジトリで公開します。`example-001` は仮の作品名です。

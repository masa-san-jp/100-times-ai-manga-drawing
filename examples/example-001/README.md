## 入力資料

| フォルダー | 内容 |
| --- | --- |
| キャラクタースケッチ | 4人の元資料 |
| キャラクターリファレンス | 設定画・生成指示・追記記録 |
| ネーム | 8ページのコマ割り・セリフ・配置 |
| 作画指示書 | 8ページの画像による指示 |

## アプリでの手順

1. このフォルダーを選び、manifest.jsonと入力資料を登録。
2. キャラクター画面でリファレンスを生成・確認し、使用する画像を採用。
3. ページ一覧からまとめて生成。
4. ページごとに採否を判定し、作画指示・修正内容を入力して必要なページだけ再生成。
5. 採用画像を書き出す。

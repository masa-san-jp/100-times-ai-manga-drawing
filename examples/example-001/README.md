# 作例001の制作資料

実際の漫画制作に使った資料を、そのままリポジトリで公開するためのフォルダーです。資料はまだ格納されていません。`example-001` は作品名が決まるまでの仮名です。公開時は作品を識別できる名前に変更します。

| フォルダー | 内容 |
| --- | --- |
| `characters/` | キャラクタースケッチ |
| `storyboards/` | ネーム |
| `instructions/` | ページごとの作画指示書 |

ネームと指示書は、対応するページが分かる名前（例：`001.png`、`002.png`）で格納します。原本の名前を維持する場合は、登録用の `manifest.json` で対応付けます。

資料が揃ったら、実ファイルの構成に合わせて `manifest.json` を追加します。このフォルダーはGitの追跡対象で、リモートへ同期すると資料も公開されます。APIキーを含む `.env` と、アプリ内部の `.data/` は引き続き追跡対象外です。

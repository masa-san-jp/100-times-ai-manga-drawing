# 100 TIMES AI MANGA DRAWING

キャラクタースケッチ、ネーム、作画指示書から、漫画の下書きをまとめて生成するローカルアプリです。ページごとに採用・要修正を判定し、指示を直したページだけ再生成できます。

[作例を見る](examples/example-001/README.md#採用した漫画8ページ) · [使い始める](#使い始める) · [制作の背景を読む（note）](https://note.com/masa_san_jp/n/n21a5c02f496f)

## できること

- 複数の作品や連載の話を分けて管理する
- スケッチからキャラクターリファレンスを生成し、採用した設定画を作画に使う
- 多数のページをまとめて生成し、完了したページから確認する
- ページごとに採否を付け、要修正ページだけ指示を直して再生成する
- 採用画像・却下候補・生成履歴を保存し、採用画像をPNGで書き出す

## 作例を見る

**[作例001：採用した漫画8ページを見る](examples/example-001/README.md#採用した漫画8ページ)**

GitHub上でそのまま閲覧できます。画像をクリックすると原寸で開きます。閲覧にはAPIキーやアプリの起動は不要です。

[制作資料一式](examples/example-001/)も公開しています。キャラクタースケッチ4枚、ネームと作画指示書各8ページ、生成したリファレンス4枚、採用画像8枚、却下候補を確認できます。

掲載8ページの生成時はスケッチを直接参照していました。現在のアプリでは、採用したキャラクターリファレンスを使います。

## 使い始める

### 必要なもの

- Python 3.12以上、uv、Git
- **GeminiのAPIキーと課金設定**（実際の作画にはAPI利用料がかかります）
- 自分のキャラクタースケッチ、ネーム、作画指示書

### ダウンロードと準備

```sh
git clone https://github.com/masa-san-jp/100-times-ai-manga-drawing.git
cd 100-times-ai-manga-drawing
uv sync --locked --extra gemini
```

### APIを設定する

リポジトリ直下の [`.env.example`](.env.example) を `.env` にコピーし、エディターで次の2項目を記入します。設定済みの `.env` はそのまま使います。

| 項目 | 記入する内容 |
| --- | --- |
| `GEMINI_API_KEY` | 自分のGemini APIキー |
| `MANGA_LIVE_BUDGET_PER_IMAGE_USD` | 画像1枚に見込む費用を米ドルで入力。例：`0.10` は10セント |

ほかの項目はテンプレートの設定で起動できます。費用の設定はアプリ内の見積もり用で、Google側の請求上限ではありません。詳しくは[設定手順](docs/operations.md#設定場所と確認)を参照してください。

### 起動する

リポジトリ直下で実行します。

```sh
uv run manga init
uv run manga web
```

別のターミナルを開き、同じディレクトリーから生成処理を起動します。

```sh
uv run manga worker
```

**[ブラウザーでアプリを開く](http://127.0.0.1:8765)**

## 漫画を制作する

1. **資料を登録する**：スケッチ・ネーム・指示書と、それらを対応付ける `manifest.json` をフォルダーに用意し、作品管理画面から登録します。[作例のフォルダー構成](examples/example-001/README.md)を参考にできます。
2. **キャラクター資料を決める**：「キャラクター資料を開く」でリファレンス画像を生成し、人物ごとに採用します。
3. **作画指示を入力する**：各ページの詳細画面で、指示書の番号に対応する文章や追加の指示を入力・保存します。
4. **まとめて生成する**：ページ一覧から未生成ページを生成します。画面には送信待ち・生成中・完了を区別して表示します。
5. **ページごとに判定する**：「採用する」「要修正にする」を選びます。修正が必要なページは指示を直し、そのページだけ再生成できます。
6. **採用画像を書き出す**：全ページ、または採用済みのページを書き出します。全ページ採用済みの場合、制作状況欄から書き出しへ進めます。

詳しい操作、複数作品・連載の管理、エラーへの対処は[利用手順](docs/operations.md)を参照してください。

## 画像の保存場所

作品を登録すると、保存用の作品フォルダーを自動作成します。ページ一覧の「作品フォルダーを開く」から確認できます。

```text
作品名/
├── キャラクターリファレンス/  人物ごとの設定画と生成指示
├── 生成結果/                  採用した漫画のPNGと出力一覧
└── 却下した候補/              却下画像と却下理由の一覧
```

画像には `0004_テイク04.png` のようにページ・テイク番号を付けます。作品フォルダーの保存場所は作品設定で変更できます。

## 現在の対応範囲と制限

- 自分のPCで使うローカルアプリです。複数人で同時利用するWebサービスではありません。
- モノクロ漫画に対応しています。カラー対応は今後の対象です。
- 作画モデルは **Gemini Nano Banana 2.1**。Batch APIを使うため、画像は依頼直後ではなく、処理完了後に表示されます。
- ページ生成で出力トークン上限に達して失敗した事例があり、対策は未完了です。採用済み画像の閲覧・書き出しは利用できます。

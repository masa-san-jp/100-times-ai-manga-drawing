## 用語としての用例

「100 TIMES AI MANGA DRAWING の工程整理を使い、ネームと作画指示を分けて下描きを試す」のように、マンガ制作へ生成AIを組み込むワークフローを指します。「100倍」は本企画のテーマであり、すべての工程・環境に対する性能保証ではありません。

## 技術的背景

このリポジトリは実行アプリではなく、制作方法と原稿草案を置く資料集です。[Claude版草案](docs/claude-draft.md) では、人間のネーム、レイアウト指示、キャラクターデザインシート、プロンプトを組み合わせて画像生成へ渡す方法を説明しています。[Gemini版草案](docs/gemini-draft.md) とあわせ、草案の記述と公開済み成果物を区別して読んでください。
